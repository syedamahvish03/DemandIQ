# DemandIQ Backend

The backend uses FastAPI and reuses the repository's existing validation and
forecasting modules. The API currently provides a health check and a CSV-driven
demand forecast endpoint.

## Requirements

- Python 3.10 or newer
- The repository's existing Python virtual environment is recommended

## Install

Run these commands from the repository root:

```powershell
.venv\Scripts\Activate.ps1
python -m pip install -r backend/requirements.txt
```

## Run the API

Run from the repository root:

```powershell
python -m uvicorn backend.app.main:app --reload --host 127.0.0.1 --port 8000
```

Endpoints:

- `http://127.0.0.1:8000/` — API information
- `http://127.0.0.1:8000/api/v1/health` — health check
- `http://127.0.0.1:8000/docs` — interactive API documentation
- `POST /api/v1/forecasts` — validate a sales CSV and generate a forecast

## Forecast request

Send a multipart form request with:

- `file`: a CSV file up to 10 MB
- `horizon_days`: 7, 15 or 30

The CSV must contain these columns:

```csv
date,store,item,sales
2025-01-01,1,101,20
2025-01-02,1,101,22
```

Each store-item series needs at least 15 consecutive daily observations. The
forecasting engine rejects duplicate or irregular daily records rather than
silently changing the input. Invalid rows and data-quality warnings are returned
in the API response. Forecast rows are generated by the existing Random Forest
forecasting function; stock levels and supplier values are not inferred.

## Run backend tests

From the repository root:

```powershell
python -m pytest backend/tests -q
```

## CORS configuration

The development frontend origins are allowed by default:

- `http://localhost:5173`
- `http://127.0.0.1:5173`

Set `DEMANDIQ_CORS_ORIGINS` to a comma-separated list of exact origins when
the frontend runs at a different address. Do not use a wildcard in production.

## Current boundary

This stage connects the React forecast page to the existing Python forecasting
engine. It does not yet provide authentication, Supabase persistence, tenant
isolation, saved forecast history, or inventory API endpoints. Do not upload
private customer information to this development endpoint; authentication and
workspace access controls are not yet implemented.
